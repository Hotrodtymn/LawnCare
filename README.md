# Lawncare

## Thomas Babb Lawn Care website

A static HTML/CSS website for a lawn-care service in Holly Springs and the surrounding Triangle area. The landing page includes a responsive viewport and service-oriented content.

> **Project type:** Portfolio project. This README describes the checked-in source rather than promising production functionality.

## Getting started

Open `index.html` in a browser.

## Notes

This repository contains the website source, not a lawn-care scheduling or payment backend.
